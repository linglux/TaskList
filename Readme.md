# TaskList

[English](Readme_en.md)

一个类似 Wunderlist 的 Windows 任务清单应用，完全离线，任务与设置保存在本机。

## 功能

- 快速添加或详细编辑任务，支持备注、清单归属和轻量／中型／重型任务权重。
- 查看今天创建的待办、全部待办或指定清单；管理清单名称与颜色。
- 完成任务并撤销最近一次完成；查看今日、本周完成数量及连续完成天数。
- 按天查看完成历史、恢复待办，生成日报并复制到剪贴板。
- 自定义完成音效与庆祝特效，支持导入不超过 10 秒的 MP3。
- 简体中文与英文即时切换，支持系统托盘和单实例运行。

## 特色：让每一次完成都有仪式感

勾选任务时，圆圈泛起涟漪、勾选标记回弹、标题划线，任务行随后淡出，同时播放完成音效和庆祝动画。轻量、中型、重型任务对应不同的庆祝强度，越重的任务，完成时越隆重。

![image-20261120100310395](./images/image-20261120100310395.png)

在 **设置 → 完成特效** 中可选择六种风格：

| 效果 | 完成时的表现 |
| --- | --- |
| 原有分级特效 | 轻量任务飘落纸屑，中型任务展示光环与成就卡片，重型任务触发全屏庆祝与鼓励文案。 |
| 为你鼓掌 | 双手拍合，搭配喝彩波纹与缤纷彩带，为完成的努力鼓掌。 |
| 极简勾选 | 轻盈回弹的勾选与细波纹，利落确认，减少视觉干扰。 |
| 完成印章 | 深红圆印、仿篆刻字形与斑驳印泥，留下收官印痕；英文界面使用 DONE 字样。 |
| 星光汇聚 | 星星逐颗点亮并连成星座，最后亮起金色主星。 |
| 礼花绽放 | 按任务权重分波升空两朵、四朵或六朵礼花，搭配双层绽放与明亮拖尾。 |

- **专属完成音效**：三种任务权重各有内置音效，也可分别导入不超过 10 秒的 MP3，试听或恢复默认。关闭音效后仍保留视觉特效。
- **随时预览**：在设置中选择轻型、中型或重型强度体验特效，不会完成任务或产生历史记录。
- **误点可撤销**：完成后出现撤销提示，方便恢复最近一次完成的任务。

## 运行与构建

需要 **Windows 和 .NET 8 SDK**。在项目根目录执行：

```powershell
# 调试运行
dotnet run --project TaskList.csproj -c Debug

# 构建发布版本
dotnet build TaskList.csproj -c Release
```

技术栈：C#、WPF、SQLite（`Microsoft.Data.Sqlite`）；WinForms 用于系统托盘。

## 使用说明

- 在 **设置 → 语言** 中切换中文或 English，默认中文，立即生效并自动保存。
- 任务标题、备注和自定义清单名称不会自动翻译。
- “今天”显示今天创建且尚未完成的任务，不是按到期日期筛选。
- 关闭或最小化窗口会隐藏到托盘；真正退出请使用托盘菜单中的 **退出 TaskList**。

## 本地数据

| 配置 | 数据库位置 |
| --- | --- |
| Debug | 项目根目录下的 `TaskList.db` |
| Release | `%LOCALAPPDATA%\TaskList\TaskList.db` |

导入的音效位于同一数据目录下的 `Sounds` 文件夹。备份前请先从托盘退出应用，再复制数据库及 `Sounds` 文件夹。Debug 与 Release 使用不同的数据目录。
